Este projeto consiste em um site interativo e responsivo voltado para sustentabilidade e tecnologias renováveis, desenvolvido com HTML5, CSS3 e JavaScript, sem dependência de bibliotecas externas. O site apresenta um cabeçalho com logo e menu de navegação, uma barra de acessibilidade com opções para alterar o tema de cores, ajustar o tamanho da fonte, trocar o idioma entre português, inglês e espanhol, e ativar a narração do conteúdo por áudio. O conteúdo principal inclui um banner com título, texto e botão de ação, seções de conteúdo com cards informativos, uma seção de vídeo com o arquivo projeto.mp4, seções de tecnologias com imagens drone.jpg, irrigacao.jpg e solar.jpg, além de uma seção de interação com contador de likes e formulário sustentável funcional com validação de campos. Os temas de cores disponíveis são colorido, branco e preto, e ao selecionar qualquer tema, todos os elementos do site se adaptam automaticamente, incluindo cards, listas, formulários e rodapé. A funcionalidade de aumento e diminuição da fonte ajusta o tamanho do texto globalmente para melhorar a leitura de acordo com a necessidade do usuário. A troca de idioma atualiza todo o conteúdo textual do site de forma dinâmica, incluindo os textos dos botões e das seções, e a narração por áudio utiliza a API SpeechSynthesis do navegador, funcionando em todos os três idiomas. O contador de likes permite interação direta do usuário e mantém o valor na sessão atual, enquanto o formulário sustentável garante envio correto das informações com mensagens de alerta, mantendo o estilo consistente com os temas de cores. Todas as imagens e o vídeo foram mantidos com os nomes originais enviados pelo usuário, preservando os créditos originais. O site é totalmente responsivo, adaptando cards, vídeos, menus e listas de tecnologias para desktops, tablets e smartphones, e todos os efeitos de hover, transições e estilos foram implementados de forma profissional para proporcionar uma experiência moderna e agradável. Este projeto é funcional em navegadores modernos como Chrome, Edge e Firefox, está pronto para uso, aprendizado ou apresentação, e serve como referência para construção de sites interativos, acessíveis e multilingues, com foco em conteúdo educativo e ambiental.
