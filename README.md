
Este projeto foi criado para o Agrinho 2026 com o tema Agro Forte, Futuro Sustentável, e o principal objetivo é mostrar que produzir alimentos e cuidar da natureza são coisas que precisam andar juntas para o nosso futuro ser seguro.
Para que todo mundo consiga acessar e entender bem essas ideias, a gente desenvolveu o site com várias opções de acessibilidade e personalização. Logo no topo, o usuário encontra a opção de idioma, onde dá para escolher entre três línguas diferentes, o que ajuda o projeto a chegar a mais pessoas.
Pensando no conforto de quem lê, também colocamos uma ferramenta para aumento de fonte, permitindo que o texto fique maior e mais fácil de enxergar, e uma opção de mudança de cor do visual, que ajusta o contraste das cores do site.
Outro recurso muito importante que incluímos é o de áudio, para que todo o conteúdo possa ser ouvido, tornando o site muito mais inclusivo.
Sobre o conteúdo, a gente explica que o agro é fundamental porque abastece as cidades e gera empregos, mas que isso deve ser feito com uma preservação ativa, cuidando das florestas e das nascentes para manter a terra fértil.
No site, mostramos exemplos reais de como a tecnologia ajuda nisso, como o uso de drones para monitorar pragas sem usar veneno demais, a irrigação gota a gota que economiza muita água indo direto na raiz da planta, e as placas de energia solar que geram energia limpa nas fazendas.
No final, o projeto ainda convida as pessoas a participarem, onde elas podem deixar o seu apoio ou enviar sugestões de novas práticas que ajudem o campo a ser cada vez mais sustentável.
