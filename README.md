Este projeto, intitulado "Projeto Agrinho 2026", é um site educativo e informativo sobre agricultura sustentável, tecnologia no campo e práticas ambientais. Ele foi desenvolvido com HTML, CSS e JavaScript, seguindo padrões modernos de desenvolvimento web e boas práticas de acessibilidade. O site possui funcionalidades avançadas, incluindo troca de idioma entre português, inglês e espanhol, alteração do tema visual com opções colorido, branco e preto, ajuste de tamanho de fonte com botões de aumentar e diminuir, além de narração do conteúdo em todos os idiomas suportados. Os textos das seções são originais e foram criados para transmitir informações completas sobre o projeto, incluindo tópicos como produção agrícola, preservação ambiental, tecnologias como drones, irrigação inteligente e energia solar, sempre mantendo uma linguagem clara e acessível para estudantes e público em geral. O site também possui interação com o usuário, permitindo registrar likes e enviar mensagens através de um formulário funcional, que valida os campos obrigatórios e exibe mensagens de alerta ou sucesso conforme necessário. Os arquivos de mídia utilizados, como vídeo e imagens, foram mantidos com os nomes originais enviados pelo usuário, sem alterações, para garantir compatibilidade e organização. Todas as funções do JavaScript foram implementadas de forma a integrar perfeitamente com o HTML e o CSS, garantindo que o site funcione corretamente sem erros, e com interface responsiva para diferentes dispositivos. O CSS foi elaborado para fornecer um visual profissional, com cores harmoniosas, botões destacados, seções bem definidas e elementos interativos com efeitos de hover e transições suaves. Este README serve como documentação básica para entender a estrutura do site, a finalidade de cada funcionalidade, e os cuidados tomados para garantir que todas as opções de acessibilidade, interação e visualização estejam operacionais. Todos os créditos dos arquivos de mídia foram mantidos conforme a versão inicial fornecida, garantindo que os nomes originais do vídeo "projeto" e das imagens "drone", "irrigacao" e "solar" estejam preservados. O site é totalmente funcional
