O Projeto Agrinho 2026 é um site educativo desenvolvido com o objetivo de apresentar a importância da agricultura sustentável, destacando como a tecnologia pode auxiliar a produção de alimentos de forma eficiente sem prejudicar o meio ambiente. O site possui um sistema de três idiomas, permitindo que o conteúdo seja visualizado em português do Brasil, inglês e espanhol. Todos os textos da página são alterados dinamicamente com base no idioma selecionado, garantindo uma experiência completa e inclusiva para usuários de diferentes nacionalidades. Além disso, o site oferece três temas de cores: colorido, branco e preto, permitindo que o usuário ajuste a aparência da página de acordo com sua preferência visual ou necessidade de acessibilidade.

O site também possui funções de aumento e diminuição da fonte, tornando a leitura mais confortável e acessível, especialmente para pessoas com dificuldade visual. Outra funcionalidade importante é a narração do conteúdo, que utiliza a API de síntese de voz do navegador para ler o texto em voz alta. Esta função suporta os três idiomas, garantindo que a experiência de áudio acompanhe a tradução textual.

Para aumentar a interatividade, o site inclui um sistema de likes, que permite ao usuário apoiar o projeto e ver o número de apoios aumentar em tempo real. Também há um formulário de sugestões ambientais, onde os usuários podem enviar ideias para práticas sustentáveis no campo. Este formulário possui validação de campos, garantindo que nenhum dado seja enviado vazio, e exibe mensagens de sucesso ou alerta conforme necessário.

O site foi desenvolvido utilizando HTML5 para a estrutura, CSS3 para o estilo e responsividade, e JavaScript para interatividade. A interface foi planejada para ser totalmente acessível, com botões claros e intuitivos, alto contraste para melhor visibilidade e uma navegação simples e objetiva. Todas as seções foram cuidadosamente estilizadas com cores harmoniosas, sombras e bordas suaves para oferecer uma experiência visual agradável e moderna. As imagens de apoio incluem drones agrícolas, irrigação por gotejamento e energia solar, além de um vídeo explicativo chamado “projeto.mp4”, proporcionando conteúdo multimídia educativo que complementa os textos.

O projeto é totalmente responsivo, funcionando perfeitamente em computadores, tablets e dispositivos móveis. Todo o código foi construído com atenção à organização, clareza e funcionalidade, garantindo que todas as funcionalidades, incluindo troca de idioma, ajuste de cores, aumento de fonte, narração em diferentes línguas, likes e envio de sugestões, estejam 100% operacionais. Para utilizar o site, basta abrir o arquivo index.html em qualquer navegador moderno. Este projeto tem como objetivo não apenas informar sobre práticas sustentáveis no campo, mas também demonstrar como a tecnologia e a interatividade podem tornar o aprendizado mais dinâmico e inclusivo, promovendo a conscientização ambiental de maneira prática e acessível para estudantes e visitantes em geral.
